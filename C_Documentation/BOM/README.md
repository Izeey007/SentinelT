# SentinelT Bill of Materials

**Project Developer:** TG Assegaai  
**Build:** SentinelT

`SentinelT_Bill_of_Materials.xlsx` is the formal procurement workbook for the physical SentinelT build. It is intended to identify the hardware and raw material that would need to be funded if SentinelT advances to hardware implementation.

The revised funding list covers the chassis/armor stock, raw mild steel, four-wheel drivetrain, independent dual-channel drive controller, 3S battery, 2.4 GHz transmitter and receiver, control board, cutter drive candidate, hammer/torso actuators, main ON/OFF isolator, E-Stop control hardware, high-current isolation relay, fuse protection, power wiring/connectors, fasteners, telemetry/warning hardware and LiPo charging/restraint equipment.

The current revised procurement total is **R15,985.04**. Prices are September 2026 retail references and must be reconfirmed when purchasing because supplier pricing and stock can change.

Hardware-stage measurements are intentionally not presented as already completed. The physical SentinelT build will follow the documented CAD, electrical and safety architecture and will be adjusted as necessary before operation so the applicable Robo Wars footprint, sub-5 kg mass, 2.4 GHz RC, ON/OFF and E-Stop requirements remain satisfied.

See `SentinelT_BOM_Procurement_Notes.md` for the drivetrain correction, safety architecture and physical-verification notes.
