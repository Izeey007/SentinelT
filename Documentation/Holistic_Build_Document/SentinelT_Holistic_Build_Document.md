# SentinelT - Robo Wars RC Combat Robot

**Designed and developed by Thato Glen Assegaai**

SentinelT is my independently designed Robo Wars RC combat robot. The detailed A4 report in this folder documents the mechanical design, 3S electronic architecture, 2.4 GHz control framework, ON/OFF and E-Stop architecture, Python/Blender verification, engineering mass budget, Bill of Materials, buildability and project ownership.
