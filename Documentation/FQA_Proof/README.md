# FQ&A Proof of Attendance

This folder is reserved for **genuine screenshots proving attendance** at Robo Rumble Facilitator Q&A sessions.

For each attended session:

1. save a screenshot showing the meeting lobby/chat/attendance evidence with the entrant username/name visible;
2. use a clear filename such as `2026-08-12_FQA_session.png`;
3. add the session date, time, facilitator, takeaway/question and relative screenshot link to `../FQA_Attendance_Log.md`.

Example link format:

```markdown
[Proof](./FQA_Proof/2026-08-12_FQA_session.png)
```

No attendance or screenshots should be fabricated. If no qualifying FQ&A session was attended, leave the log truthful rather than inventing evidence.
