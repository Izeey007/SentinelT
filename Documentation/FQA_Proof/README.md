# FQ&A Proof of Attendance

This folder is reserved for **genuine screenshots proving Facilitator Q&A attendance**.

For each attended session:

1. save a screenshot showing the meeting lobby, chat or attendance evidence with the participant name/username visible;
2. use a clear filename such as `2026-08-12_FQA_session.png`;
3. add the session date, time, facilitator, takeaway/question and relative screenshot link to `../FQA_Attendance_Log.md`.

Example:

```markdown
[Proof](./FQA_Proof/2026-08-12_FQA_session.png)
```

Attendance evidence is never fabricated. If no qualifying session was attended, the log remains truthful and unfilled.
